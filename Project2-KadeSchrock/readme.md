# How to Run
## Run the interface.py file in Problem1/Code and choose and input option
### Input Options
- 1 = start left, both dirty
- 2 = start left, left dirty
- 3 = start left, right dirty
- 4 = start left, both clean
- 5 = start right, both dirty
- 6 = start right, right dirty
- 7 = start right, left dirty
- 8 = start right, both clean
## After typing in input option choose to run DFS of BFS
